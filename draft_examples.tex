\section*{Single Day Planner Layout Options}
\subsection*{For A5 Paper (15.6cm × 20.9cm)}

\textbf{Changes from current:}
\begin{itemize}
  \item Hours: 6--20 (instead of 7--23) — saves $\sim$2cm vertical space
  \item Top priorities: 3 (instead of 8) — saves $\sim$2.5cm vertical space
  \item Total space saved: $\sim$4.5cm to reallocate
\end{itemize}

% ============================================
\subsection*{Recommendation Summary}

\begin{enumerate}
  \item \textbf{Option 1} -- Best for habit tracking enthusiasts
  \item \textbf{Option 2} -- Best for balanced task/note users who want wellness tracking
  \item \textbf{Option 3} -- Best for priority-focused planning
  \item \textbf{Option 4} -- Best for minimal, distraction-free planning
\end{enumerate}

\vspace{5mm}

\subsection*{Configuration Changes Required}

All options require these base changes in \texttt{cfg/base.yaml}:

\begin{verbatim}
layout:
  numbers:
    dailytodos: 3          # Changed from 8
    dailybottomhour: 6     # Changed from 7
    dailytophour: 20       # Changed from 23
\end{verbatim}

\textbf{Template modifications:} Only \texttt{tpls/\_common\_05\_daily.tpl} needs changes for Options 1-3. Option 4 requires additional changes to \texttt{tpls/schedule.tpl}.
